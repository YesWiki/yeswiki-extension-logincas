# yeswiki-extension-logincas

 - [English](#english)
 - [Français](#français)

## English

[YesWiki](https://yeswiki.net/) extension replacing the login form by a centralised
authentication on a CAS server.

### Authors

 - Florian Schmitt
 - and all contributors indicated on this page : <https://github.com/YesWiki/yeswiki-extension-logincas/graphs/contributors>

### Install

In page `GererMisesAJour` on your YesWiki website, search extension `logincas` and install it.

The extension installs safely. As long as `cas_host` is not set, it stays inactive:
a message reports the missing configuration and the usual YesWiki login form keeps
working.

### Usage

Usage help is described in `http://example.com/?doc/#tools/logincas/en/README.md` (replacing `http://example.com/?` by the `baseUrl` of your wiki). The same file can be found also here : https://github.com/YesWiki/yeswiki-extension-logincas/blob/master/docs/en/README.md

## Français

Extension [YesWiki](https://yeswiki.net/) qui remplace le formulaire de connexion par
une authentification centralisée sur un serveur CAS.

### Auteurs

 - Florian Schmitt
 - et tous les contributeurs et toutes les contributrices indiqués sur cette page : <https://github.com/YesWiki/yeswiki-extension-logincas/graphs/contributors>

### Installation

Dans la page `GererMisesAJour` de votre YesWiki, recherchez l'extension `logincas` et installez-la.

L'extension s'installe sans rien casser. Tant que `cas_host` n'est pas renseigné, elle
reste inactive : un message signale la configuration manquante et le formulaire de
connexion habituel de YesWiki continue de fonctionner.

### Utilisation

L'aide sur l'utilisation peut être trouvée sur `http://example.com/?doc/#tools/logincas/fr/README.md` (en remplaçant `http://example.com/?` par `baseUrl` de votre wiki). Le même fichier peut aussi être trouvé ici : https://github.com/YesWiki/yeswiki-extension-logincas/blob/master/docs/fr/README.md
